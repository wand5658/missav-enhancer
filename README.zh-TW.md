# MissAV Enhancer

[English](README.md) | **繁體中文**

**missav.ai** / **missav.ws** 的非官方 Chrome 擴充功能（Manifest V3）。切到別的分頁或視窗時影片不會自動暫停，另外重新設計了網站版面，讓瀏覽更方便。所有功能都可以在工具列的設定面板裡開關和調整。

與網站本身無關。不收集任何資料，也不會連到任何外部伺服器，詳見[隱私](#隱私)。

## 功能

- **防止自動暫停**：`Alt+Tab`、`Ctrl+Tab` 或點到其他視窗時，影片會繼續播放。自己按暫停（播放器按鈕、空白鍵）照常有效。
- **封面輪播**：首頁、`/dm<n>/*`、`/saved` 頂端是全螢幕的輪播，內容取自該頁的影片。每張有模糊的封面背景、從封面淡入靜音預覽片段、標題、上一張／下一張、進度條，換張時隨機套用一種轉場（視差、縮放、3D 翻轉）。頁面背景會跟著當前封面變色。
- **首頁橫向列**：首頁各區塊改成 Netflix 式的橫向捲動列，有吸附捲動、露出下一張的一角、左右箭頭、←/→ 切換卡片，滑鼠移上去卡片會放大。
- **列表工具列**：篩選與排序的下拉選單改成一直顯示的按鈕（點一次就好，不用點兩次），固定在頁首下方，旁邊附迷你換頁器。
- **列表分頁**：大的上一頁／下一頁按鈕、以目前頁為中心的頁碼、跳頁輸入框，←/→ 也能換頁。
- **劇院模式影片頁**：播放器佔滿整個寬度、高度剛好符合視窗，四周有影片封面模糊成的光暈。「接著看」改成橫向列，緊接在播放器下方。
- **滿版版面、捲動淡入、隱藏廣告。**

## 安裝

需要 Chrome 111 以上（Edge 等 Chromium 系瀏覽器也可以）。

1. 到 [Releases](../../releases) 下載最新的 `missav-enhancer-*.zip`，解壓到一個固定的位置。Chrome 是直接從這個資料夾載入，裝完後不能刪。
2. 開啟 `chrome://extensions`，打開右上角的**開發人員模式**。
3. 點**載入未封裝項目**，選剛解壓出來、裡面有 `manifest.json` 的那個資料夾。

也可以直接 clone 這個 repo 後載入它的目錄，不需要建置。

### 更新

用這種方式安裝的擴充功能**不會自動更新**。更新方法：下載新版、覆蓋資料夾內容，到 `chrome://extensions` 按擴充功能卡片上的重新載入，再重新整理已經開著的網頁。設定會保留。

## 設定

點工具列上的圖示（要先從拼圖選單把它釘選出來）。面板會依瀏覽器語言顯示繁體中文或英文。每一組（防止自動暫停、封面輪播、首頁、列表頁、影片頁、外觀與動畫、廣告）都有總開關和各自的選項。大部分的修改會立刻套用到開著的分頁；少數會改變頁面結構的項目會特別標示，並提供重新載入的按鈕。設定會在登入同一個帳號的瀏覽器之間同步，也可以重設、匯出、匯入（JSON）。

## 隱私

- 唯一的權限是 `storage`，只用來存你的設定（`chrome.storage.sync`）。
- 只能存取 `missav.ai` 和 `missav.ws`。
- 沒有背景程式，擴充功能本身不發送任何網路請求。輪播的內容是從頁面上已有的影片卡片取得。
- 沒有任何分析或追蹤。

## 其他網域

這個網站常換網域。要加新網域，需要改 `manifest.json` 裡的**三個**地方：`host_permissions`，以及兩個 `content_scripts` 各自的 `matches`。改完後重新載入擴充功能。漏改任何一個，擴充功能都只會部分生效。`popup.js` 的 `SITE` 正規表示式可以一起改，但它只影響面板上的「目前在本站」狀態顯示。

如果網站出了新的官方網域，歡迎開 issue 或發 PR。

## 失效時

這個擴充功能依賴網站內部的頁面結構和全域變數 `player`。網站一改，功能就會失效，而且不會有任何錯誤提示。請[開 issue](../../issues/new/choose)，附上網域、頁面類型（首頁／列表／影片頁）和 Chrome 版本。

## 運作原理

網站的三個暫停處理器（`window` blur、`document` blur、`visibilitychange`）最後都會呼叫 `window.player.pause()`，`window.player` 是一個 [Plyr](https://plyr.io/) 實例。如果直接攔截這些事件，會弄壞頁面上其他也在聽這些事件的功能，所以 `anti-pause.js` 改成在 `document_start` 時、在頁面的 main world 裡，搶在頁面指派之前替 `window.player` 裝上 accessor，再把該實例的 `pause` 包起來。只有在 700 ms 內（可調）有點擊、按鍵或觸控時才放行暫停，所以你自己按的暫停有效，失去焦點造成的暫停會被擋掉。另有備援機制：如果有程式直接對 `<video>` 呼叫 `pause()`，會自動恢復播放。

版面改造是掛在 `<html>` class 底下的純 CSS，腳本只負責標記元素、插入自己的節點、量測尺寸，不會改動 Alpine.js 控制的元素的 `display`。完整的架構說明和失效時用 Console 排查的步驟在 [`CLAUDE.md`](CLAUDE.md)（英文）。
